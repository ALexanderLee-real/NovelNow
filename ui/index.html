配图工坊

使用须知

先读这个
  1. 需要本地预装并配置好 ComfyUI：本程序只负责把生图任务丢给你自己的 ComfyUI，不内置任何生图模型。
  2. 准备一份工作流 JSON（ComfyUI 里「导出 (API)」得到的 API 格式），并把正向提示词节点的文本里写上 {{PROMPT}} 占位符——生成时会替换成剧情摘要。
  3. 默认连接 http://127.0.0.1:8188（ComfyUI 默认端口）。本程序只发起出站连接，不会占用或开放任何端口。
  4. 跨机器使用：ComfyUI 启动时加 --listen 0.0.0.0 并放行 8188/TCP，然后把下面的地址改成那台机器的 http://IP:8188。
  5. 生成的图存在程序目录 舞台图片\ 下（每项目一个子文件夹，节点名.png），自动铺到剧情分支的舞台背景。
